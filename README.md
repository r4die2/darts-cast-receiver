# Табло CalcURate

Откройте `preview.html` в браузере для просмотра примера игры без Chromecast.
Файлы `index.html`, `style.css` и `receiver.js` должны находиться рядом с ним.
Пример включается только параметром `?preview`; при обычном запуске отображается реальная игра.

Для проверки изменений в консоли браузера: `CalcURatePreview.throw(60)` — уменьшить остаток,
`CalcURatePreview.nextPlayer()` — сменить игрока, `CalcURatePreview.reset()` — вернуть пример.
`leg-win-preview.html` открывает отдельный экран победы в леге; в основном превью его
также можно показать через `CalcURatePreview.finishLeg(0)`.
`bot-leg-preview.html` показывает тот же экран победы с подходами бота и информацией
о турнире из записи базы.
Для публикации замените соответствующие файлы GitHub Pages этой версией.
Показ последнего подхода требует обновлённого приложения, которое отправляет `lastVisit`.
Последний корректный снимок табло сохраняется в хранилище Web Receiver и
показывается после перезапуска приёмника до получения нового сообщения. При
восстановлении виден статус ожидания подключения; актуальный счёт по-прежнему
передаёт телефон. Хранилище может быть очищено телевизором или платформой.
